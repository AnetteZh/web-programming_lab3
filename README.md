# web-programming_lab3

Веб-версия игры 2048, где пользователь имеет возможность:

* Взаимодействовать с игровым полем
* Записать свой рекорд в таблицу лидеров в случае окончания игры
* Просмотреть список лидеров
* Продолжить игровую сессию с последнего действия
* Вернуться на один шаг назад
* Начать игру заново

В игре реализовано каскадное объединение плиток:

состояние ряда - [2, 2, 2, 2], после движения влево - [8, 0, 0, 0]

Игра завершается при невозможности совершить движение плиток в любую из 4х сторон

---
Логика игры (JS код) разделена на модули:
1. Game - непосредственно игровая логика: перемещение, объединение плиток, очки, проверка окончания игры.
2. Storage - сохранение и загрузка игры, рекордов и истории ходов.
3. UI - отображение поля, плиток, счёта, модальных окон.
4. Controls - обработка клавиатуры, кнопок и свайпов.
5. Main - запуск приложения и связывание всех модулей.
   
Это позволяет, например, изменять внешний вид игрового поля, не переписывая алгоритм перемещения плиток.
